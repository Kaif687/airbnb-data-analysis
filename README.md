# Airbnb Data Analysis & Visualization

## Overview

This project focuses on analyzing and visualizing Airbnb listing data using Tableau.

The analysis explores Airbnb listings based on factors such as price, location, room type, revenue, and availability to identify patterns and trends in the Airbnb market.

## Objective

The objective of this project was to transform Airbnb data into an interactive Tableau dashboard and identify meaningful trends and insights.

The analysis focuses on:

- Airbnb listing prices
- Revenue generated by listings
- Number of listings
- Average price by location
- Revenue trends over time
- Listing availability
- Distribution of listings across different room types
- Geographic patterns in Airbnb listings

## Tools Used

- Tableau
- Excel / CSV

## Analysis & Visualization

The Tableau dashboard was designed to provide an interactive overview of Airbnb listings and their performance.

Key areas explored include:

### Pricing Analysis

Analyzed Airbnb prices across different locations and listing types to identify pricing patterns.

### Revenue Analysis

Examined revenue trends and compared revenue performance across different time periods and locations.

### Location Analysis

Analyzed the geographic distribution of Airbnb listings and identified areas with higher concentrations of listings.

### Room Type Analysis

Compared different room types to understand their distribution and pricing differences.

### Availability Analysis

Examined listing availability to identify patterns in how frequently properties were available for booking.
